# Security and data handling

This is a personal learning lab. Commit only synthetic fixtures and reviewed output.
Never upload credentials, Terraform state or plans, customer information, employer
code, internal logs, or live investigation reports. Ignoring a file does not remove
it from Git history. Revoke any accidentally exposed credential before cleaning history.
Do not submit sensitive vulnerability details in public issues. Use GitHub private
vulnerability reporting if enabled, or report only a minimal synthetic reproduction.
No project automatically contains hosts, disables users, or changes cloud access.
